# The read script

Just the words. `//` = breathe. **Bold** = let it land, don't push it.
~400 words. Reads at 3:00 without rushing. Director's-commentary voice —
one person across a table, not a house.

---

### 0:00 — COLD OPEN  *(black, then the two headlines)*

Last year, a judge blocked a finished film from being released. //
Not over the story. Over **the title**. //

And right now Netflix is defending a **hundred-and-seventy-million-dollar**
lawsuit // over five words: *this is a true story.* //

Both of those were findable before anybody rolled a camera.

---

### 0:20 — SETUP  *(landing page, prod URL visible)*

Every script has landmines like that. // Brands. Songs. Artwork. Real people. //

Studios pay up to three thousand dollars, and wait two weeks, for a person to
read a screenplay line by line and find them. // And nothing ships without it —
no clearance, no insurance, no distributor. //

This is ClearanceRoom. // A deterministic agent built on Gemini, Google's Agent
Development Kit, and the Parallel Search API. //

Let me just run it.

---

### 0:40 — THE RUN  *(click RUN CLEARANCE — let it breathe)*

This is a short noir I wrote, and I salted it with real problems. //

One click. // Gemini reads the script and pulls out every clearable item. //

*(pause — let the ticker climb, 3–4 seconds of silence)*

Now Parallel is researching every one of them on the live web. // Real searches.
Real sources. Landing as they finish. //

There's the Beatles song, // **blocked** — six figures to license. //

The Casablanca clip playing on the diner TV — **blocked** — and it's citing
Warner Brothers' actual clip licensing page. //

And here's my favorite. // I invented a diner. I called it the Blue Comet. //
The agent found a **real** Blue Comet Diner // that ran in Hazleton,
Pennsylvania, for eighty years. //

A model working from memory calls that name fictional. //
**Live research calls it a lawsuit.** //

*(zoom the banner)*

Seventy-two seconds. Fourteen live searches. Fifty-six sources. //
A person doing this takes a week.

---

### 1:40 — DEEP DOSSIER  *(click it on the Hey Jude card)*

Finding the problem is half of it. // A producer's next question is *what do I
do about it.* //

So on any flagged item, ClearanceRoom runs Parallel's Task API — deep research
against a structured schema. // Rights holders. Licensing path. What it costs.
Who's sued over it. //

And every single field // comes back with **its own confidence rating** and its
own citations. //

It found the publisher. It found a reported six-figure comparable. // It found
the lawsuit over the Sesame Street parody. // And it found a cheapest cure that
*saves the scene* — re-record it as a cover, license the composition only. //

That's not a summary. That's a working brief.

---

### 2:15 — TITLEGUARD  *(type SITUATIONSHIPS)*

Remember the film that got blocked? // Type its title. //

**Blocked. Risk ninety-five.** // It found the trademark filing, the web series
from 2016, and the injunction itself. //

It just reproduced a federal judge's finding // in forty seconds.

---

### 2:35 — THE BINDER  *(scroll; check two AI boxes; export)*

And it all lands where producers actually live. // Every finding maps onto the
twelve clearance procedures that E-and-O underwriters require — in their own
language, cited. //

Disclose your AI usage, and it checks current carrier exclusions. Live. //

Then you export it. //

---

### 2:50 — CLOSE  *(end card)*

One script goes in. // The document that unlocks your insurance, your financing,
and your release // comes out. //

ClearanceRoom. // Every frame cleared.

## Two notes before you roll

- The **silence** during the run is doing work. Don't fill it.
- Say "a hundred and seventy million dollars" **flat**. The number sells itself.
